There are four datasets with the three primary ones (bullet points) all interrelated:

* Principal aquifers (2023-09-15): This includes alluvial / glacial aquifers as a separate layer
* Secondary hydrogeologic regions(v2.0 2022-06-29): Areas outside of principal aquifers
* Hydrogeologic settings (v2.0 2026-01-06): This is a combination of the first two datasets that also includes well counts and median well depth

The current recommendation is to triplify the alluvial / glacial aquifers and the principal aquifers from the hydrogeologic settings dataset.
Secondary hydrogeologic regions can be triplified from the hydrogeologic settings data as needed.
